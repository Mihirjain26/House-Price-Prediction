# House Price Prediction

This project is an end-to-end machine learning application that predicts house prices using Python and Scikit-learn. I'm building it from scratch to strengthen my understanding of the complete ML workflow while following software engineering practices used in real-world projects.

Rather than focusing only on training a model, this project emphasizes clean code, modular design, reproducible experiments, and a production-oriented project structure.

## Objectives

* Understand the complete machine learning pipeline
* Perform data cleaning and exploratory data analysis (EDA)
* Engineer meaningful features
* Train and compare multiple regression models
* Evaluate models using appropriate regression metrics
* Write clean, maintainable, and reusable code
* Follow professional Git and GitHub workflows

## Tech Stack

* Python
* NumPy
* Pandas
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook
* Git & GitHub
